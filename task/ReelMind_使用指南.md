# ReelMind 使用指南

更新时间：2026-06-21

## 1. 产品定位

ReelMind 当前是验证优先工具。

它的第一目标不是生成视频笔记，而是回答：

```text
这句话到底有没有可靠联网证据支持？
```

系统会把文本或 URL 拆成可核实主张，联网检索多个来源，抓取网页/PDF 正文，判断信源等级和风险，再生成可审计核验报告。

## 2. 启动

双击根目录：

```text
run.bat
```

打开：

```text
http://127.0.0.1:3015/
```

后端健康检查：

```text
http://127.0.0.1:8483/api/sys_check
```

如果直接打开 `http://127.0.0.1:8483` 出现 `{"detail":"Not Found"}`，这是正常现象。后端只提供 API。

## 3. 配置

联网核实至少需要：

- 可用后端；
- 可用搜索供应商配置；
- 可选的 OpenAI-compatible 模型配置，用于辅助查询构造或解释。

最终判定不是模型自由判断，而是规则引擎基于正文证据得出。

DeepSeek/OpenAI-compatible provider 示例只写占位符，不要把真实 API key 写入仓库。

## 4. 核实文本

1. 打开 Web 工作台。
2. 在左侧输入框粘贴待核实文本。
3. 点击 `开始联网核实`。
4. 等待任务完成。
5. 在报告中查看逐条主张、证据、来源和风险。

报告中的关键字段：

- `supported`：高可信正文证据支持。
- `refuted`：高可信正文证据反驳。
- `mixed`：不同高可信证据之间存在口径冲突。
- `insufficient`：有相关材料，但核心元素覆盖不足。
- `data_void`：弱来源、低独立性、抓取失败或证据空缺。
- `source_risk`：伪权威、注入、重定向异常、阻断域名等来源风险。

## 5. 核实 URL

1. 输入网页 URL。
2. 系统先抓取输入源正文。
3. 从正文提取 atomic claims。
4. 对每条主张联网检索和交叉判定。

报告顶部会展示输入源审计：

- request/fetched/canonical URL；
- redirect chain；
- title/publisher/author/date；
- fetch status；
- text chars。

## 6. 阅读报告

报告分为：

- 总体判定；
- 主张统计；
- 风险旗标；
- 输入源审计；
- 逐条主张判定；
- 正文证据；
- 来源矩阵；
- cache/geo/audit 信息。

每个来源会显示 tier：

- A：官方、监管、统计、法院、标准、原始研究等。
- B：可信机构、主流媒体、出版社、权威数据库等。
- C：百科、博客、转载类来源。
- D：论坛、社交、营销、SEO、榜单、弱身份来源。
- blocked：本地、阻断或不安全来源。

只有搜索摘要、论坛、社交、SEO、榜单或营销页不能单独产生 `supported`。

## 7. 重新核实

报告支持：

- 整个任务重跑；
- 单条 claim 重跑。

重跑会尽量复用已完成 claim 结果，只重试需要重新检索、抓取或抽证的部分。重跑期间旧报告保留可见。

## 8. 历史任务

资料库会显示核验状态。

没有 `verification_result` 的旧视频笔记会标记为：

```text
未联网核实
```

打开旧笔记后，联网核实页会提供：

```text
发起联网核实
```

旧笔记完成核实后，才会成为可审计核验报告。

## 9. 兼容视频笔记

旧视频笔记能力仍可作为次级产物使用：

- 抖音精选输入；
- 音频转写；
- Markdown 笔记；
- 思维导图；
- 知识卡片；
- AI 问答。

这些内容不等于事实已被验证。需要进入联网核实报告查看证据。

如果旧抖音输入失败，再检查 Cookie：

```text
http://127.0.0.1:8483/api/downloader_cookie_status/douyin
```

浏览器扩展当前发布形态是 popup，主要用于提交当前页面 URL/文本到核验任务，并保留抖音输入诊断。

## 10. 常见问题

### 为什么没有 supported？

系统会保守处理以下情况：

- 搜索不可用；
- 只有 snippet；
- 正文抓取失败；
- 来源等级弱；
- 来源之间不独立；
- 存在 prompt injection、fake authority、canonical anomaly、redirect anomaly；
- 高可信证据同时支持和反驳。

### 为什么旧笔记显示未联网核实？

旧笔记缺少可审计 `verification_result`。点击 `发起联网核实` 生成证据报告。

### 为什么仍看到 Markdown、导图和卡片？

它们是兼容的次级阅读产物。当前第一屏和主工作流以核验报告为准。

## 11. 推荐演示路径

1. 打开工作台。
2. 粘贴一条可验证主张。
3. 生成核验报告。
4. 展示证据片段和来源 tier。
5. 过滤 `refuted`、`data_void` 或 `source_risk`。
6. 对单条 claim 重跑。
7. 打开一个旧笔记，展示 `未联网核实` 和 `发起联网核实`。
