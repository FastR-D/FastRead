# Reel Mind 使用指南

## 1. 产品用途

Reel Mind 用来把知识视频生成 AI 笔记。当前 demo 优先面向抖音精选知识视频，支持生成 Markdown 笔记、思维导图、知识卡片，并可以对当前视频或历史知识库进行 AI 问答。

## 2. 快速启动

### 2.1 推荐方式：本地唯一入口

适合非开发人员演示和体验。

1. 在项目根目录双击 `run.bat` 启动整套服务。
2. 如需检查依赖，在项目根目录运行 `run.bat --check`。
3. 浏览器打开后访问：

```text
http://127.0.0.1:3015/
```

4. 查看服务状态可运行 `run.bat --status`。
5. 停止服务可运行 `run.bat --stop`。

### 2.2 开发方式：源码启动

适合需要调试代码的场景。

后端默认开发地址：

```text
http://127.0.0.1:8483
```

前端默认开发地址：

```text
http://127.0.0.1:3015
```

后端根路径不是页面入口，直接打开 `http://127.0.0.1:8483` 出现 `{"detail":"Not Found"}` 是正常现象。

## 3. 首次使用前配置

### 3.1 配置 AI 模型

生成笔记和问答需要先配置模型。

1. 打开 Reel Mind 页面。
2. 进入“设置”。
3. 打开“AI 模型设置”。
4. 新增模型供应商。
5. 填写供应商名称、Base URL、API Key。
6. 获取或手动添加模型名称。
7. 启用要使用的模型。

当前项目适合使用兼容 OpenAI SDK 的中文模型供应商，例如 DeepSeek 或 Qwen。

### 3.2 配置转写方式

默认可使用 `bcut` 转写方式，适合中文视频 demo。也可以在设置页切换到 faster-whisper、Groq 或 MLX Whisper。

如果选择本地 Whisper，首次使用可能需要下载模型。模型越大，转写精度通常越高，但速度更慢、占用空间更多。

### 3.3 同步抖音 Cookie

抖音精选视频解析可能依赖登录态。如果出现视频详情为空、提示登录或下载失败，需要同步 Cookie。

推荐方式：

1. 在浏览器中登录抖音精选。
2. 使用项目浏览器扩展同步 Cookie。
3. 回到 Reel Mind 后重试生成笔记。

兜底方式：

1. 打开“设置”里的下载配置或 Cookie 配置页。
2. 复制浏览器中的抖音 Cookie。
3. 粘贴到 Cookie 输入框。
4. 点击同步。
5. 查看状态是否显示已配置、字段有效。

## 4. 生成第一条笔记

1. 打开首页。
2. 在“视频链接”中粘贴抖音精选视频链接，例如：

```text
https://www.douyin.com/jingxuan?modal_id=7633777410067926322
```

3. 确认平台选择为“抖音”。
4. 选择可用的 AI 模型。
5. 选择笔记风格和需要生成的内容格式。
6. 可选填写收藏夹、标签和收藏备注。
7. 点击“生成笔记”。
8. 等待任务完成。

任务会依次经过解析、下载、转写、总结等阶段。完成后，右侧会展示生成结果。

## 5. 阅读和复习

### 5.1 Markdown 笔记

Markdown 视图适合详细阅读。通常包含目录、摘要、重点内容、来源信息和思维导图专用章节。

### 5.2 思维导图

点击顶部“思维导图”按钮，可以把笔记中的 `## 思维导图` 章节渲染为可视化导图。该视图适合快速理解主题结构。

### 5.3 知识卡片

点击“知识卡片”按钮，可以查看结构化卡片和评分。

常见卡片类型包括：

- 核心结论
- 知识要点
- 概念解释
- 操作步骤
- 风险提醒
- 行动清单
- 金句

顶部三项评分含义：

- 信息密度：判断视频内容是否有足够知识含量。
- 可信度：判断内容是否存在明显低可信风险。
- 可执行性：判断内容是否能转化为具体行动。

### 5.4 可信度核验

知识卡片视图中可能展示可信度核验结果。需要进一步检查时，可点击“联网核验”。系统会尝试检索外部来源，对部分关键说法进行补充判断。

## 6. 我的收藏

生成成功的笔记会自动进入“我的收藏”。

你可以：

- 点击收藏卡片重新打开笔记。
- 编辑收藏夹名称。
- 添加或修改标签。
- 填写收藏备注，例如“为什么收藏”“下次复习重点”。
- 刷新页面或重启服务后继续恢复历史收藏。

建议按主题建立收藏夹，例如：

- 学习方法
- AI 工具
- 副业案例
- 产品分析
- 生活技能

## 7. AI 问答

### 7.1 当前视频问答

打开某条笔记后，可以在 AI 问答中提问。系统会基于当前视频的标题、转写文本和笔记内容回答。

示例问题：

- 这条视频最重要的三个结论是什么？
- 视频里提到的步骤能不能整理成清单？
- 这条视频有哪些风险或不确定的地方？
- 如果我要今天开始执行，第一步做什么？

### 7.2 知识库问答

在问答面板中切换到“知识库”模式后，可以跨历史笔记提问。

示例问题：

- 我之前收藏过哪些关于时间管理的内容？
- 多个视频对 AI 工具使用有什么共同建议？
- 帮我整理一下所有副业相关视频的行动清单。

知识库问答依赖历史笔记数量。笔记越多，召回结果越丰富。

## 8. 常见问题

### 8.1 打开后端地址显示 Not Found

这是正常情况。后端是 API 服务，不是网页入口。

本地模式请打开：

```text
http://127.0.0.1:3015/
```

### 8.2 生成失败或视频详情为空

优先检查：

- 抖音 Cookie 是否已同步。
- Cookie 是否过期。
- 视频链接是否能在浏览器正常打开。
- `run.bat --status` 是否显示前后端正常。
- 模型供应商和 API Key 是否可用。

### 8.3 没有可选模型

进入“设置 - AI 模型设置”，确认已经添加供应商、模型名称，并且模型处于启用状态。

### 8.4 转写很慢

如果使用本地 Whisper，速度取决于机器性能和模型大小。可以尝试：

- 使用更小的模型。
- 切换到 bcut。
- 使用 GPU 环境。
- 先用较短视频测试。

### 8.5 知识卡片为空

旧笔记可能没有保存知识卡片数据。可以重新生成该视频笔记，或刷新任务列表后让后端尝试补充生成。

### 8.6 知识库问答效果不明显

知识库问答需要足够多的历史笔记。建议先生成多条同主题视频笔记，并尽量添加清晰标签和收藏夹。

## 9. 推荐使用流程

1. 先配置模型和 Cookie。
2. 用一条短视频测试生成是否成功。
3. 阅读 Markdown 笔记确认内容完整。
4. 切换思维导图理解结构。
5. 查看知识卡片和三项评分。
6. 给笔记补充收藏夹、标签和备注。
7. 用当前视频问答做复习。
8. 生成多条笔记后，使用知识库问答做跨视频整理。
