# FastRead 使用指南

更新时间：2026-08-05

## 产品定位

FastRead 是面向单篇论文的分页阅读工作台。默认路径是：

```text
PDF / 论文 URL -> 分页原文 -> 关键问题报告 -> 方法与贡献
-> 300 字个人总结 -> 带页码持续追问
```

联网核验保留为可选证据审计层，用于判断外部支持、反证、冲突与信源风险；它不与论文导入并列，也不替代论文原文。

## 启动

双击根目录 `run.bat`，打开：

```text
http://127.0.0.1:3015/
```

## 导入与分页

1. 点击“导入论文”。
2. 优先选择本地 PDF，也可粘贴论文详情页或 PDF URL。
3. 进入“分页原文”，确认页数与文字。
4. 如果页面提示只解析了部分页，报告和问答同样只能覆盖已解析范围。

扫描版、加密、空白或不可解析 PDF 会失败关闭。

## 阅读报告

点击“关键问题”，生成报告。报告必须覆盖：

- 研究问题；
- 方法过程；
- 主要贡献；
- 实验或证据；
- 局限。

保留的引用必须能在指定原文页面逐字匹配。身份 Gate 只说明论文身份，不说明论文主张已被外部证据支持。

## 300 字总结

打开“300 字总结”，用自己的话记录问题、方法、贡献与疑点。总结最多 300 字，与 AI 报告分开保存。

## 持续追问

打开“持续追问”。回答应优先引用论文分页原文并显示页码；当前上下文没有支撑页面时，应明确回答“原文证据不足”。

## 可选证据层

需要外部支持、反证、撤稿状态或信源风险判断时，打开“可选证据层”。外部检索结果不能升级为实验复现证据。

## 结束

```powershell
.\run.bat --stop
```
