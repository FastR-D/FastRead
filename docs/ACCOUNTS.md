# 账号与管理员

Go 服务关闭公开自主注册。管理员可创建本地账号；首次 FastCAS 登录可填写邮箱、姓名及本地密码，经 CAS 确认后创建账号和个人资料库。已有邮箱应先本地登录再绑定。

FastCAS 已验证的 `profile.role=admin` 在登录或绑定成功时自动授予平台管理员权限，适用于新账号和已有账号。普通 FastCAS 角色保留本地已有管理员权限。

「用户管理」提供搜索、创建、编辑邮箱和姓名、设置角色、启用/停用、密码重置和删除。管理操作记录原因，凭据、角色和状态变更会撤销会话。删除账号保留工作区及资料，停止账号访问。系统保护当前管理员和最后一名启用管理员。

现有「管理后台」继续提供共享模型配置、工作区分配及运行状态。

用户管理接口为 `/api/admin/users`，使用 `GET/POST` 和 `PATCH/DELETE /{user_id}`。CAS 注册使用 `GET/POST /api/auth/fastcas/registration`；浏览器绑定的注册状态五分钟有效，两次回调必须是同一 CAS 身份。密码仅以散列保存，账号、个人工作区和待激活绑定事务性创建。
