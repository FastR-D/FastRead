# Research reading tools

Reviewed on 2026-11-12 against the repositories' current documentation.

| Project | Useful interaction | FastRead integration |
| --- | --- | --- |
| [PaperQA2](https://github.com/Future-House/paper-qa) | Retrieve document passages before answering; cite individual sources in multi-document answers | Knowledge-library questions and selected-paper direction generation use saved page excerpts. Results retain source IDs and open the relevant paper. |
| [Zotero](https://github.com/zotero/zotero) | Organize papers, annotations, citations, and reusable research collections | Knowledge libraries keep paper membership and notes together. Export includes BibTeX, citation metadata, page-linked evidence, and personal notes for writing. |
| [ScholarPhi / Scholar Reader](https://github.com/allenai/scholarphi) | Augment the PDF in place using document entities and bounding boxes | Reading annotations retain page rectangles; evidence navigation opens the source page alongside reports and notes. |

The workflow combines these interactions with the FastRD services: FastNews
imports paper metadata into the reader; selected reading evidence becomes an
editable research direction in FastNews; FastWrite receives an immutable bundle
and returns project notes to the corresponding reading notebook.

The implementations use FastRead's Go API and existing React reader. Each
service connection belongs to a workspace and is established with a revocable
connection code generated by the destination account.
