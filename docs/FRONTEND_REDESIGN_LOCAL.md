# FastRead 前端改版：本地首版

日期：2026-09-22。基于已核对的 Web 主线 `7c085d4`，本地分支为 `codex/reader-product-local-20260922`。

本次前端改版通过 GitHub 独立分支交付，暂不创建 PR 或部署。界面验收使用本地隔离资料库；预览脚本、数据和截图保留在本机，不随分支提交。

## 可以体验的内容

- 文献库从大卡片集合改为紧凑列表，提供服务端标题搜索、标签筛选、分页、批量加入知识库和归档恢复。
- 文献库、知识库、笔记形成统一导航；公开论文检索与本地文献搜索分开。
- 最近阅读入口来自实际打开过的论文，不生成虚构进度。
- PDF 与链接导入统一使用可键盘操作的弹窗，高级模型参数收起；上传失败保留已选文件。
- 知识库目录使用简洁集合卡片，仍连接现有多资料阅读、问答和关系矩阵。
- 笔记入口可按知识库或论文查看、创建、编辑保存的笔记，并保留返回原文版本与页码的引用。
- 阅读器默认优先展示 PDF；辅助栏可收起、拖动或用方向键调整宽度。页码、缩放和辅助栏偏好可恢复。
- 阅读笔记显示未保存状态，继续使用本地草稿与服务端显式保存；没有将本地草稿伪装为跨设备同步。
- 导入与生成状态放入处理记录，连接中断时说明显示的是旧状态；已有任务和引用协议沿用后端。
- 路由使用 URL 与浏览器历史；搜索条件、知识库、论文、文档版本和显式页码可以通过刷新恢复。

## 验收中修复的问题

- 旧的全局表单列布局影响新搜索框，已对新的搜索表单明确行布局。
- 公共 PDF.js 文件在 Vite 开发模式下被追加 import 查询并拒绝加载，改为同源绝对运行时 URL；正式静态路径保持不变。
- 首次打开阅读器时，重复的资料刷新可能覆盖引用指定页码。现在在异步请求之前保留打开目标，阻止兜底恢复覆盖显式引用位置；浏览器验收覆盖从已读第 2 页返回第 1 页引用。
