## 5. 抖音 Cookie 状态

本轮已经通过插件或接口写入抖音 Cookie。

确认接口：

```text
GET http://127.0.0.1:8483/api/get_downloader_cookie/douyin
```

最后确认：

- `HasCookie = True`
- Cookie 长度约 `6192`

重要结论：

- 无 Cookie 时，抖音详情接口返回空响应
- `yt-dlp` 对同一视频也提示需要 fresh cookies
- 当前主流程依赖有效抖音 Cookie

后续如果再次失败，优先检查：

1. Cookie 是否过期
2. 是否重新同步 Cookie
3. 后端是否读取到最新 Cookie
